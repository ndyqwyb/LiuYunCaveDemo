# LiuYun — 留云借风洞天复刻 Demo

> 用 **UE 5.5 + C++/蓝图混合开发**，复刻《原神》璃月魔神任务第一章第一幕秘境「留云借风洞天」的**关卡与机关玩法**。
> 定位：**10～20 分钟可完整通关的垂直切片（档位 B）**，无战斗、无滑翔。
> 用途：个人作品集，投递米哈游等游戏公司的 **Gameplay 程序 / 关卡策划** 实习与校招。

## 🎮 玩什么（30 秒看懂）

- 单人解谜关卡，**无战斗、无滑翔**
- 核心：**旋转光桥 + 两处火柱谜题 + 风场电梯**
- 8 个流程阶段、11 个节点：①入口石厅 → ②火方碑岛 → ③转盘 → ④操控台 → ⑤转盘 → ⑥三轮谜题 → ⑦宝箱4·风场 → ⑧操控台 → ⑨转盘 → ⑩环谜题 → ⑪终点庭院
- 场景：**悬浮在青碧虚空中的空中遗迹**，11 个节点用石桥 / 金色光桥连接（不是洞穴！）

## 🔧 技术要点

- **C++ 负责**：玩家角色、交互系统、机关基类与状态机、谜题算法、关卡流程总控
- **蓝图负责**：机关表现层（材质 / 特效 / 音效）、UI、演出
- **架构**：接口 + 基类 + 事件广播 → 机关可复用、可配置
- 引擎：**UE 5.5** ｜ 项目路径：`E:\UE_projects\LiuYun`
