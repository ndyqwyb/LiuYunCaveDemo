# Docs/Images · 截图库

存放**本项目自己的**开发进度截图，供 `DevLog.md` 与 `Progress/PROGRESS.md` 引用。

> ⚠️ 原版游戏截帧考据素材在 `../_ref_analysis/`，那个目录不进公开仓库；这里只放自己项目的截图。

## 命名约定

`M{里程碑}_{内容}_{序号}.png`，例如：

    M1_player_walk.png       M1 手感定稿的走路截图
    M2_blockout_top.png      M2 灰盒俯视图
    M2_platform_A.png        M2 平台 A 截图
    M9_lighting_final.png    M9 美术期光照定稿

## 在 DevLog 里引用

    ![M2 灰盒俯视](Images/M2_blockout_top.png)

（`DevLog.md` 在 `Docs/` 下，所以路径以 `Images/` 开头。）

## 体积提醒

单张建议压到 **500 KB 以内**（1080p PNG，或 JPEG 质量 85）。
`Docs/` 下的图片不走 Git LFS，单张过大会永久留在仓库历史里。
