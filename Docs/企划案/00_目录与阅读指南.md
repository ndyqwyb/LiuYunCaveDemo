# 留云借风洞天 · UE5 复刻 Demo 企划案

> **项目代号**：LiuYun
> **目标平台**：Windows PC（UE 5.5，C++ + 蓝图混合）
> **项目定位**：个人作品集 Demo，用于投递米哈游等游戏公司 **Gameplay 程序 / 关卡策划** 实习或校招
> **版本**：v0.3（结构重构版）　**日期**：2026-09-26
> **预计周期**：12 周 / 约 145～223 小时

---

## 🎯 一句话说清这个项目

复刻《原神》璃月魔神任务第一章第一幕中的秘境 **「留云借风洞天」** 的**机关与关卡流程**：一个漂浮在青碧虚空中的空中遗迹，玩家点燃火方碑、旋转金色光桥、解开两处记忆/联动谜题，最终面见留云借风真君。

**不做**：战斗、滑翔、抽卡、角色养成、大世界。
**重点**：**机关系统的程序实现 + 关卡动线设计**，美术尽量交给 AI 与现成素材。

## 📖 这套文档怎么用

### 阅读顺序（按你的进度，不要一次全读）

| 阶段 | 先读这些 | 什么时候读 |
|---|---|---|
| **现在（开工前）** | `01` 定位与合规 → `02` 关卡考据 → `04` 蓝图/C++ 协作 | 建立正确认知，避免方向性错误 |
| 想清楚要做什么 | `02` 关卡考据 → `03` 机关设计规格 | 理解 8 个流程阶段、11 个节点与 7 种机关 |
| 动手搭环境 | `06` 环境搭建实操（含 C 盘 / DDC / 网络） | 按步骤执行，M0 |
| 开始搭关卡 | `07` 关卡搭建与地编实操 | M2 白盒起 |
| 开始写代码 | `04` 蓝图与 C++ 协作 → `03` 机关规格 | M3 交互系统起 |
| 找素材 / 建模 | `05` 美术与资产管线（**Tripo3D 主线**） | M9 起，也可提前做道具 |
| 每周末打卡 | `08` 里程碑与打卡 | 每周日 |
| 卡住了 / 报错了 | `09` 风险与踩坑速查 | 随时 |
| 准备投简历 | `11` 作品集与面试 | M9 之后 |

### 这套文档的分工原则

- **`01`～`03` 回答「做什么」**——定位、考据、机关规格。改的是设计。
- **`04`～`07` 回答「怎么做」**——代码协作、美术管线、环境、地编。改的是执行。
- **`08`～`11` 回答「怎么不崩」**——节奏、风险、复盘、呈现。
- **`12`** 是速查附录，忘了某个 API / 路径就来这里翻。

> 💡 **所有文档里的代码、路径、参数都是「可直接照抄」的建议值。** 遇到拿不准的地方，**先照抄跑通，再回来理解原因**——你是来练 Gameplay 的，不是来学理论考试的。

## ⏱️ 现在该做的三件事

1. **读完 `01` 和 `02`**（约 30 分钟）——搞清楚这个项目「是什么」和「不做什么」。
2. **执行 `06` 的 M0 清单**——C 盘空间、显卡设置、Git 初始化、首次编译。
   > ✅ **DDC 环境变量已于 2026-09-27 写入注册表并核实完成**（`UE-LocalDataCachePath` → `E:\UE_DDC\Local`），详见 `06` 的 6.7。
   > ⚠️ 你的 C 盘只剩 **约 18 GB**，这仍是**头号风险**，必须先清理再往下走。**重启 UE 后记得删掉 C 盘的旧 Zen 缓存**，这一条也要做。
3. **打开 `08` 的第 1 周计划**，从 M0 开始打卡。

## 🔑 三句话记住整个项目

> **① 这是一条空中的路，不是一个洞。** 11 个浮空节点 + 金色光路 = 全部空间逻辑。
> **② 你的核心资产是「机关系统」，不是美术。** 机关要自己写得干净、可复用、可扩展。
> **③ 版权红线不能碰。** 不用官方模型、不用官方音频、不用官方贴图；角色用原创，素材全部登记在 `AssetCredits.md`。
