## 第一部分 · 原版考据（事实基线）

### 一、最重要的一句话结论

留云借风洞天**不是**一个洞穴，也**不是**一个标准「秘境副本」。

它是璃月魔神任务第一章第一幕「浮世浮生千岩间」中，奥藏山「留云」支线的**任务专属洞天**——一个悬浮在青碧色虚空中的**空中遗迹秘境**，由若干浮空石台、金色光路、旋转桥机关和火元素方碑构成。

v0.1 把它写成了「洞穴 + 岩窟 + 地下遗迹」，方向是错的，必须整体推翻重做美术方向。

### 三、任务背景（洞府之前发生的事）

这一段是「为什么玩家会进洞府」，复刻时可以选择做、也可以直接跳过。

1. 玩家在奥藏山寻找留云借风真君，发现石桌和**三把石椅**，椅背刻字：
   - 「此处居留云」
   - 「此处坐归终」
   - 「此处借帝君」
2. 找到**三处烹饪痕迹**（对应三把椅子）：
   - 西侧：金鱼草 + 莲蓬 + 豆腐 → 珍珠翡翠白玉汤
   - 东南：肉类 + 面粉 → 摩拉肉
   - 东北：松茸 + 兽肉 → 松茸酿肉卷
3. 去水池边的烹饪台，做出这三道菜。
4. 回到石椅，把三道菜**供奉**上去。
5. 留云借风真君现身，发出挑战：「闯过洞府」。
6. 走上台阶，**叩访仙府**，进入洞天。

> 复刻建议：这一整段是「剧情 / 烹饪小游戏」，对 Gameplay 复刻价值低、制作成本高。**建议 P2 级**，只做简化版（三个可交互的供奉点 + 一段对话），或者干脆不做。

### 四、洞府内部完整流程（核心）

以下为**复刻的主体**。写成阶段式，方便直接对应关卡设计。

#### 阶段 1 · 入口石厅（教学 + 触发）

- 场景：室内石制大厅，有台阶、门扉、石柱，青蓝色环境光。
- 玩家点燃第一个**火元素方碑**。
- 触发与留云借风真君的**对话**。
- 对话结束后，挑战正式开始。

> 原版此处接的第一个挑战是「两分钟内击败 10 只史莱姆」。
> **本 Demo 删除战斗**，必须替换。建议替换为：点燃方碑 → 光路亮起 → 第一个旋转桥机关解锁。

#### 阶段 2 · 旋转桥教学（第一个机关）

- 场景：平台中央有一个**方形石柱机关**（可旋转）。
- 玩家操作机关旋转，使**金色光路 / 光桥**对准下一个平台。
- 走上光桥，前往下一座浮空岛。

> 这是全洞天最具代表性的机关，也是**最优先复刻的对象**。
> 攻略记录的操作：逆时针 90°（或顺时针 270°）。

#### 阶段 3 · 浮空岛 A · 火柱谜题（第一处）

- 场景：一座浮空圆形石台，周围有**火元素方碑 / 火柱**，背后有**三个上锁的宝箱**。
- 原版此处有丘丘人战斗（**删除**）。
- 玩家需要完成**三轮难度递增的解密**，每成功一轮解锁一个宝箱。
- 三轮全部完成后，**对面的风场自动开启**。
- 🔧 **本 Demo 调整（已定）**：风场开启条件改为**把三个已解锁的宝箱全部打开**——光完成三轮谜题还不够，必须逐箱交互开启。这让「开宝箱」从可选奖励变成**推进流程的必要步骤**，也让「谜题 → 奖励 → 通路」的因果更清晰。

**谜题规则（★★）：**

- 机关会给出一段「哪几个柱子亮过」的提示，玩家必须**按同样的顺序**依次点燃。三轮序列越来越长。
  - 社区记录示例：第一轮 1-5-4，第二轮 3-5-1-4，第三轮 2-4-1-5-3
  - 站位说明：站在机关处正对火柱，从左往右编号 1~5
  - 注意：不同玩家遇到的序列不同（可能是随机生成），所以不要照抄序列，要复刻**规则**

#### 阶段 4 · 风场上升

- 三轮火柱解密完成后，对面平台自动生成**上升气流 / 风场**。
- 🔧 **本 Demo 调整（已定）**：风场在**三个宝箱全部打开**后才激活；宝箱只解锁不开，风场保持关闭。
- 原版玩家是**借助风场 + 滑翔**飞到上一层平台。

> **本 Demo 处理**：滑翔不是核心玩法，且实现成本（滑翔 Pawn、俯冲、体力、动画、相机）偏高。
> 建议**保留风场、删除滑翔**：风场直接把玩家向上托举到上层平台，也就是「电梯式上升气流」。这样既保留了原版的视觉地标和关卡节奏，又省掉一整套滑翔系统。

#### 阶段 5 · 光桥连转（第二个旋转机关）

- 到达上层平台后，再次旋转方形石柱机关。
- 攻略记录的转向序列（米游社版）：顺 → 顺 → 逆（返回第二个机关）→ 顺 → 顺
- 另有版本：逆时针 → 顺时针 → 解锁风场 → 再逆时针 → 后面顺逆都可以
- 目的：把光路依次接到下一座浮空岛。

#### 阶段 6 · 浮空岛 B · 联动火柱谜题（第二处）

- 场景：另一座浮空石台，**六个火元素方碑**围成一圈。
- 规则：**点燃一个，左右相邻两个状态反转**。
- 目标：六个全部点亮。
- 最简解法：把初始**没有亮的那些柱子**依次点一遍即可（不需要精确顺序）。
- 六个全亮后，**旋转方形石柱 90°**，光路直通终点。

#### 阶段 7 · 终点庭院 · 面见留云

- 走光路到达最后的石质前庭。
- 场景中有**仙鹤 / 白鹭**、石灯、台阶。
- 与**留云借风真君**对话，任务完成。

#### 阶段 8 · 收尾

- 弹出结算 / 剧情字幕，回到大世界。

### 六、视觉与美术考据（★★★）

#### 视觉 1 · 场景类型

- **不是洞穴**。是「洞天」——一个独立的、悬浮在虚空中的秘境空间。
- 主体是**多座浮空石台 / 浮空岛**，之间用**金色发光光路（光桥）**连接。
- 天幕是明亮通透的**青碧色 / 青蓝色**虚空（不是夜晚、不是地下）。
- 远景有巨大树木、瀑布状光柱、飘浮的碎石与光点。

#### 视觉 2 · 色彩板

- 主色：青碧 / 蓝绿（#3FB8C8 · #1F6E7A · #2E8C99）
- 高光 / 光路：暖金色（#FFD98A · #F2B33D · #E8A33D）
- 机关强调色：深红 + 橙（#B2354A · #C8455C · #FF5C3A）
- 石材：冷灰绿（#7E948F · #A8B6B1）
- 环境雾：青白色体积雾，远景泛白

#### 视觉 3 · 关键道具外观

- **火元素方碑 / 火柱**：⚠️ **2026-09-26 截帧修正——不是圆柱形，是扁平的矩形「门框 / 牌坊」造型**：红色发光的矩形外框 + 框内符文面板 + 顶部悬浮的红色水晶 / 火焰。未激活时暗淡，激活时通体红光 + 粒子。（做成一个 Box 环 + 发光材质即可，建模成本极低。）
- **圆形石拱门**：场景中有**巨大的圆形石拱门**（青灰色石材，立在平台上），既是构图框架也是地标。复刻时可用一个圆环 + 石材材质代替，性价比很高。
- **地面刻纹**：圆形石台上是**同心圆 + 同心方框**的几何刻纹，这是场景里辨识度最高的图案，**优先做**。
- **方形石柱机关**：深蓝色 / 青色方形石柱，四面有方形发光纹样，可整体旋转，顶部有机关核心。
- **小石灯**：青蓝色方形灯罩，内部有橙色火光，环绕在石台边缘，是很好的「节奏点」装饰物。
- **光路 / 光桥**：由金色线条 + 发光地板组成，会把两个平台连接起来，是整个关卡最强的视觉引导。
- **地面**：圆形石台，带同心圆刻纹与几何纹样。
- **终点**：石阶、门扉、白鹤、石灯，一个庄严的前庭。

#### 视觉 4 · 氛围关键词

仙侠 · 洞天福地 · 青碧虚空 · 浮空遗迹 · 金色光路 · 火与石 · 静谧机关

**玩家动线（草图原文，一字不改）**

`① → ②(旋转) → ③ → ④(旋转) → ⑤ → ⑥ → ⑤ → ④(旋转) → ⑤ → ⑦ → ⑧(旋转) → ⑨ → ⑩(旋转) → ③ → ⑪`

| 次序 | 在哪操作 | 作用 | 转了哪个盘 |
|---|---|---|---|
| 1 | ② 号岛火方碑点亮 → 操控台解锁 | 把 ③ 号盘转到 **2↔4** | ③（第 1 次） |
| 2 | ④ 号台操控台 | 把 ⑤ 号盘转到 **4↔6** | ⑤（第 1 次） |
| 3 | ④ 号台操控台（回程后再用） | 把 ⑤ 号盘转到 **4↔7** | ⑤（第 2 次） |
| 4 | ⑧ 号台操控台 | 把 ⑨ 号盘转到 **8↔10** | ⑨（第 1 次） |
| 5 | ⑩ 号台操控台 | 把 ③ 号盘转到 **10↔11** | ③（第 2 次） |

> 🎯 **共 5 次旋转，4 个操控台**（②、④、⑧、⑩）。④ 号台用两次，这就是「一个固定岛对应一个转盘」的复用价值——**代码只写一遍，关卡里摆 4 份**。
> 🎯 ⑤ 号盘（90° 型）是全场唯一「同一操控台要转两次」的地方：第一次把玩家送去 ⑥ 做谜题，第二次把玩家送去 ⑦ 拿宝箱 4。**这是本关最好的设计点，面试时可以单独讲。**

**为什么不会死锁（必读）**

- ⑤ 号盘第一次对准 4↔6，玩家从 ④ → ⑤ → ⑥。做完谜题后原路回 ⑥ → ⑤ → ④（此时 ⑤ 仍对准 4↔6，路还在，**回得去**）。
- 回到 ④ 号台再转一次 ⑤ 号盘 → 对准 4↔7 → 从 ④ → ⑤ → ⑦。**不存在「上去了下不来」**。
- 风场是**双向**的：⑧ 号岛（高）想回 ⑦ 号岛（中）时，往南走进风场体积 → 被抬到柱顶悬停 → 再往南移出 → **自由落体落到 ⑦ 号岛**。所以**不需要额外的死锁保护，也不要做单向阀门**。
- 全部 5 次旋转的**目标朝向之间都只差 90°**，玩家往任一方向转都能到达目标朝向（走反了多转一次而已），**不存在转到死角出不来**。

**通关条件**：打开全部 5 个宝箱，并到达终点 ⑪。因为 ③–⑪ 的光桥要等 ⑩ 号岛操控台解锁（环形谜题解开后才解锁）才能接通，**「开满 5 个宝箱 + 到终点」这个条件在流程上自动成立**，不需要额外写判定。

### 2.5 视觉引导的三层设计

**第一层 · 光（远景）**
- 未接通的平台之间，光桥保持**暗金色虚线微亮**（让玩家知道「那边将来有路」）
- 当前目标的平台上方有一道**淡淡的光柱**
- 背景青碧色 `#1F6E7A`，保证暖金 `#FFD98A`、红橙 `#FF5C3A` 都很跳

**第二层 · 路（近景）**
- 光桥是**唯一能走的地方**，其余都是虚空
- 桥边有细金描边，桥面有流动光点
- 未接通 = 暗金虚线 + 无碰撞；接通 = 明亮实线 + 完整碰撞（**逐段亮，不要瞬间全亮**）

**第三层 · 交互（微观）**
- 可交互物件统一语言：**边缘发光 + 轻微呼吸**
- 靠近时统一提示「按 E ○○」
- 交互成功立刻三连反馈：**音效 + 光路亮起 + 轻微震动**

> 🔍 检查方法：截一张图缩到手机大小，还能一眼看出「下一步去哪」吗？看不出就重做引导。

### 2.6 白盒（Blockout）制作流程

白盒 = 用最简单的方块搭出空间，**只验证尺寸和路线**。

1. 新建关卡 `L_LY_Blockout`（**不要在正式关卡上直接搭白盒**）
2. 用 `SM_LY_Blockout_Cube` / `SM_LY_Blockout_Cylinder` 按 **2.1 节点总表**摆出 ①～⑪，**先只摆 Z 高度和 XY 位置，不摆装饰**
3. 用细长方块（宽 350）搭出 2.1 连接表里的 11 条边，高差用斜坡
4. 用彩色方块标出机关位置（火方碑=红、操控台/转盘=金、宝箱=绿、风场=蓝）
5. 放 `PlayerStart` 在 ① 号岛，朝向 ②
6. **全程用脚跑一遍**：①→②→③→④→⑤→⑥→⑤→④→⑤→⑦→⑧→⑨→⑩→③→⑪
7. 调尺寸直到「走得顺」，再开始做机关
8. 定稿后 `Git commit`，消息 `M2: blockout v1 approved`

**白盒验收清单（必须全过）**
- [ ] 出生点能看见 ② 号岛的火方碑
- [ ] 11 条边都能正常走过，不掉下去
- [ ] 每条光桥的坡度 ≤ 30°，走上去不会打滑感
- [ ] 站在任一平台都能看到「下一个目标」的线索
- [ ] 转盘石路残段旋转时**不超出平台边界**
- [ ] 风场能把玩家稳定送到 ⑧ 号岛，**且能反向回 ⑦ 号岛**
- [ ] 掉落虚空会被 KillVolume 送回检查点
- [ ] 全程跑完 12～18 分钟

### 阶段 1 · ①入口石厅 → ②火方碑岛

**只教一件事：走近 → 看提示 → 按 E。**

| 项 | 内容 |

| 场景 | ① 号厅：3 级台阶、2 根石柱、石灯；①–② 石桥（宽 600、上坡 ≈25°）；② 号岛：1 个火方碑 + 1 个操控台 |

| 反馈链 | ① 点燃音效 ② 方碑亮度过渡 0.25s ③ 轻震动 ④ 操控台亮起并弹「按 E 转动机关」 |

| 验收 | 提示必现；按 E 必成功；音效与灯光在 0.5s 内出齐 |

### 阶段 2 · ③ 180° 转盘（第一次旋转，教学关）

**全场最重要的教学关，教的是「本 Demo 的核心玩法：转盘 + 光桥」。**

| 项 | 内容 |
|---|---|
| 场景 | ② 号岛操控台；③ 号转盘（Ø1600，石路残段 700×350 两条，呈 180°） |
| 动线 | 在 ② 号台按 E → ③ 号盘匀速转 90° → ②–③ 与 ③–④ 逐段亮起 → 走过 ③ 到 ④ |
| 机关行为 | **两个交互点：左转 −90° / 右转 +90°**；一次转一个 `RotationStep = 90°`；转完卡位 |
| 反馈 | 转动中有机械音；停下有「咔」卡位音；接通瞬间光桥**从近到远逐段亮**（0.4s/段） |
| 对话 | 留云：「此间路石，需以巧劲转之。」 |
| 技术点 | `ALY_RotatingBridge`（继承 `ALY_MechanicBase`）+ 2 × `ULY_InteractComponent`；旋转用 `FMath::FInterpConstantTo` 匀速插值 |
| 参数 | `RotationStep = 90.0f`、`RotationDuration = 0.8f`、`TargetAngleTolerance = 5.0f` |
| 易错点 | ① 旋转后碰撞没跟着转（转整个 Actor，或把碰撞挂在旋转组件上）② 玩家站石路上被甩下去（`bIsRotating` 时禁止交互，并让玩家站**圆盘中心**操作）③ 角度用 `==` 永远不成立（必须容差比较） |
| 验收 | 玩家最多 3 次交互接通；接通反馈明显到「不用看攻略也知道成了」 |

| 验收 | 玩家不需要新提示就能完成 |

### 阶段 4 · ⑥ 三轮火方碑谜题（本 Demo 最难的谜题）

**规则**：5 根方碑里随机生成一条递增序列，玩家按相同顺序复现。每完成一轮解锁 1 个宝箱。

| 轮次 | 序列长度 | 示例（原版参考） | 倒计时 | 奖励 |
|---|---|---|---|---|
| 第 1 轮 | 3 | 1 – 5 – 4 | 40 s | 珍贵宝箱（宝箱 1） |
| 第 2 轮 | 4 | 3 – 5 – 1 – 4 | 55 s | 精致宝箱（宝箱 2） |
| 第 3 轮 | 5 | 2 – 4 – 1 – 5 – 3 | 70 s | 普通宝箱（宝箱 3） |

> ⚠️ **不要硬编码这 3 组数字**，实现「规则 + 随机生成」（序列放 `DA_LY_PuzzleConfig`）。这是面试加分项。

**状态机**：`Sealed → Countdown → ShowingSequence → WaitingInput → Evaluating → RoundComplete → AllComplete`

**流程细节**
1. 玩家踏上 ⑥ 号岛 → 5 根方碑**全部处于封印态**（每根一个 Ø260 透明能量罩）→ 走到石碑（谜题开关）→ 按 E
2. 开关交互 → **本轮所有方碑的罩子打开** + **倒计时立刻开始**（含播放顺序的时间）+ 系统播序列（每根亮 0.6s、间隔 0.3s、音高递增）
3. 播完 → 全部熄灭 → 提示「按顺序点燃方碑」→ 此时才允许交互
4. 点对 → 该方碑保持点亮 + 清脆音；点错 → 全体闪红 + 低沉音 + **只重置当前轮**
5. 本轮完成 → 对应宝箱解锁（播解锁音）→ 屏幕出现**宝箱符号 + 指向箭头**（**多个待开宝箱时只指最近的一个**，开掉后自动指下一个）
6. 三轮完成 → 宝箱 1·2·3 全部解锁
7. **倒计时归零** → 方碑**重新封印**（退回 `Sealed`），但 **`CompletedRounds` 保留**，玩家再按一次开关即可重开当前轮

| 项 | 规格 |
|---|---|
| 关键属性 | `TArray<ALY_FirePillar*> Pillars`、`TArray<int32> CurrentSequence / PlayerInput`、`int32 CurrentRound / CompletedRounds`、`MaxRounds = 3`、`float RoundTimeLimit` |
| 进度保存 | 已完成轮次写进 `CompletedRounds`，**超时和失败都不清空**；只有「点错」才重置当前轮 |
| 事件 | `OnSequenceStarted`、`OnPillarFlashing(int32)`、`OnRoundComplete(int32)`、`OnCountdownTick(float)`、`OnRoundSealed()`、`OnPuzzleCompleted()` |
| 蓝图负责 | 方碑特殊材质、倒计时 UI（数字 + 进度条，剩 10s 变红并加速心跳音）、开罩/封印音效 |
| 易错点 | ① 播序列时玩家能提前交互 → 必须锁输入 ② 点错没有明显反馈 ③ 轮次之间不加 1～2s 停顿，玩家分不清轮 ④ 罩子带碰撞 → 挡住交互射线（**`ALY_Seal` 必须 `NoCollision`**） |
| 验收 | 每轮都要按一次开关才开罩；倒计时可见且逐轮变长；超时后重新封印但已完成轮次不丢；三轮完成 → 宝箱 1·2·3 解锁 |

### 阶段 5 · 回程 → ⑤ 第二次旋转 → ⑦ 宝箱 4 → 风场开启

| 项 | 内容 |
|---|---|
| 动线 | ⑥ → ⑤ → ④（**原路返回，⑤ 仍朝向 4↔6，路还在**）→ 在 ④ 号台再按一次 E，把 ⑤ 转到 **4↔7** → ④→⑤→⑦ |
| 宝箱 4 | **无前置条件**，到达 ⑦ 号岛即可按 E 开启 |
| 风场开启 | 宝箱 4 打开后，累计打开 = 4（1·2·3·4）→ `ALY_GameFlowManager` 调 `SetFieldActive(true)` |
| 反馈 | 开箱音效 + 封印罩以**溶解材质**慢速消散（1.2～1.8s，**不要用缩放消失**）；风场开启时地面圆环由暗转亮 + 一声低沉的「轰」 |
| 屏幕指引 | 每次解锁宝箱 → HUD 出「宝箱符号 + 箭头」；多个待开时**只指最近的一个** |
| 关键设计 | 这一段是**喘息节拍**：有走路、有回程、有开箱，没有新机制 |
| 验收 | 玩家不需要任何提示就知道「要回 ④ 号台再转一次」——因为 ⑤ 号盘上只有 ⑦ 那条石路残段是亮的 |

### 阶段 6 · 风场上升（⑦→⑧，零重力匀速电梯）

| 项 | 内容 |
|---|---|
| 场景 | ⑦ 号岛边缘一个 Ø800 圆柱风场（可见气流柱 + 上升粒子 + 风声），**与 ⑦、⑧ 接壤但不重合**（两侧各留 ≈100 uu） |
| 动线 | 走进柱体 → **零重力匀速升到柱顶 +1650** → 悬停 → 朝北按 W 移出 → 恢复重力 → 落到 ⑧ 号岛（顶面 +1200） |
| 机关行为 | ① 上升段：每帧直接写 `Velocity.Z = RiseSpeed`（**匀速，不是给力**）② 悬停段：`Velocity.Z = 0` + `GravityScale = 0`，只动 XY ③ 出柱：还原重力，自由落体接管 |
| 关键参数 | `RiseSpeed = 600`（uu/s）、`ColumnHeight = 1050`（+600 → +1650）、`FieldRadius = 400`、`CeilingTolerance = 30`、`bTopPushEnabled = false` |
| 双向 | **从 ⑧ 号岛往南走进柱体 → 被抬到柱顶 → 往南移出 → 自由落体落到 ⑦ 号岛。**所以不存在「上去下不来」的死锁，**不要做单向阀门** |
| 技术点 | `ALY_WindField`（体积 + 参数 + 通知 `EnterWindField/ExitWindField`）+ `ALY_PlayerCharacter`（改 CMC 参数 + 施力）。**施力写在角色身上，不写在风场身上** |
| 蓝图负责 | 地面发光圆环 `SM_LY_WindRing`（未激活暗 / 激活亮）+ 上升气流 Niagara + 风声 |
| 易错点 | ① 用 `AddForce` 累加 → 越飞越快飞出地图 ② 忘调 `AirControl = 1.0` → 柱内按 W 没反应 ③ 风场体积和 ⑧ 号岛可行走面**重叠** → 边缘变成「踩上去就飘」 ④ 出柱不还原 `GravityScale` ⑤ ⑧ 号岛近侧放栏杆 → 玩家撞栏掉下去 |
| 验收 | 站进去一定到 ⑧ 号岛，**不可能失败**；反向也回得来 |

> 🛫 **为什么不保留滑翔**：滑翔要额外做空中控制、体力、落地判定、动画、镜头，是独立系统级工作量。风场只需要「把人从低处送到高处」，**垂直气流完全替代**。正式决策见 `01_项目定位与版权合规.md`。

### 阶段 7 · ⑧ 操控台 → ⑨ 转盘 → ⑩ 环谜题岛（宝箱 5）

| 项 | 内容 |
|---|---|
| 动线 | 在 ⑧ 号台按 E → ⑨ 号盘转到 **8↔10** → ⑧→⑨→⑩ |
| ⑩ 号岛谜题 | **6 根方碑围成一整圈（R850）**；交互一根 → **自己 + 左右相邻两根**的亮灭状态全部取反；目标是把 6 根全部点亮 |

| 验收 | 谜题必定可解；宝箱 5 打开后累计 5/5 |

## 🐛 常见坑

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 机关按「大世界尺度」做（底座 600×600） | 火方碑在平台上像根牙签，比例失真 | 按 2.3 表做：火方碑 150×150 底座、总高 ≈220 |
| 把 `Ø` 当成半径 | 平台做成 2 倍大，机关全散开 | 全文统一：`Ø` = 直径，`R` = 半径；`Ø1600` 就是 R800 |
| 转盘只做一个方向 | 玩家要走错方向时无法纠正，体验差 | **两个交互点：左转 −90° / 右转 +90°** |
| 转盘石路残段超出平台边界 | 转动时悬空穿模 | 残段长 700 < 半径 800，只铺一段 |
| 风场做成单向 | 玩家不敢往上走，怕下不来 | **双向可通行**；⑧ 号岛南侧不放栏杆 |
| 照抄某个攻略的「火柱序列」 | 装错机关、谜题数量不对 | ⑥ 号岛是记忆顺序、⑩ 号岛是联动翻转，两处是不同的 |
| 谜题答案硬编码 | 面试减分 | 序列放 DataAsset，实现「规则 + 随机」；环形谜题用 BFS 验证可解 |
| 高度档凑成「每座岛都不同」 | 坡度和风场高度全要重算 | 只用低 0 / 中 +600 / 高 +1200 三档 |
| 光桥只做「能走」不做「引导」 | 玩家迷路 | 三层引导：光（远景）+ 路（近景）+ 交互（微观） |
| 一开始就在正式关卡上搭白盒 | 改坏了没法回退 | 白盒在 `L_LY_Blockout`，定稿后再复制成 `L_LY_Domain` |
| 插入了原神截帧当贴图 | 版权风险 | 截帧只用于本地考据（`_ref_analysis/`），绝不出现在工程与作品中 |
