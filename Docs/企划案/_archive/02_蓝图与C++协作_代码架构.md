## 1. 心智模型：为什么这样分层

### 1.1 一句话规则

> **C++ 定规则，蓝图做表现，关卡摆实例。**

### 1.2 三层结构图

```
┌────────────────────────────────────────────────────────┐
│  第 3 层 · 关卡实例（Level Instances）                  │
│  - 在关卡里摆放 BP_LY_FirePillar_01 等                  │
│  - 在 Details 面板填参数（MechIndex = 1）               │
│  - 只配置，不写逻辑                                      │
└───────────────────────┬────────────────────────────────┘
                        │ 继承
┌───────────────────────▼────────────────────────────────┐
│  第 2 层 · 蓝图表现层（Blueprint）                       │
│  - BP_LY_FirePillar（继承 C++ ALY_FirePillar）          │
│  - 换材质、播 Niagara、放音效、做动画                    │
│  - 不写玩法规则                                          │
└───────────────────────┬────────────────────────────────┘
                        │ 继承
┌───────────────────────▼────────────────────────────────┐
│  第 1 层 · C++ 逻辑层（Source）                          │
│  - ALY_FirePillar（继承 ALY_MechanicBase）              │
│  - 状态、事件、判定、数值                                  │
│  - 不含任何美术资源引用                                   │
└────────────────────────────────────────────────────────┘
```

### 1.3 为什么这样分（用「旋转桥」举例）

| 如果全写在蓝图里 | 如果全写在 C++ 里 | 三层分工（推荐） |
| --- | --- | --- |
| 逻辑连线一坨，改一处要翻半天 | 每次调材质都要编译，痛苦 | 逻辑改 C++，表现改蓝图，互不干扰 |
| 无法被别的系统复用 | 美术无法参与调整 | 美术可以在蓝图里自由调整 |
| 版本控制无法 diff（文本可 diff，但蓝图是二进制） | 逻辑能 diff | 逻辑能 diff，表现能预览 |

## 5. 交互接口 `ILY_Interactable`

### 5.1 头文件

```cpp
// LY_Interactable.h
#pragma once
#include "CoreMinimal.h"
#include "UObject/Interface.h"
#include "LY_Interactable.generated.h"

UINTERFACE(MinimalAPI, BlueprintType, Blueprintable)
class ULY_Interactable : public UInterface
{
    GENERATED_BODY()
};

class LIUYUN_API ILY_Interactable
{
    GENERATED_BODY()

public:
    /** 现在能不能交互？（可用来做冷却、锁定判断） */
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "LY|Interaction")
    bool CanInteract(AActor* Interactor) const;
    virtual bool CanInteract_Implementation(AActor* Interactor) const { return true; }

    /** 执行交互 */
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "LY|Interaction")
    void Interact(AActor* Interactor);
    virtual void Interact_Implementation(AActor* Interactor) {}

    /** 交互提示文字（"按 E 点燃"） */
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "LY|Interaction")
    FText GetInteractPrompt(AActor* Interactor) const;
    virtual FText GetInteractPrompt_Implementation(AActor* Interactor) const
    {
        return NSLOCTEXT("LY", "DefaultPrompt", "交互");
    }

    /** 是否高亮（用于描边/发光） */
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "LY|Interaction")
    void SetHighlighted(bool bHighlighted);
    virtual void SetHighlighted_Implementation(bool bHighlighted) {}
};
```

### 5.2 蓝图如何实现这个接口

1. 蓝图类 → Class Settings → Interfaces → Add → `LY Interactable`。
2. 在蓝图里会出现三个事件：`Can Interact`、`Interact`、`Get Interact Prompt`。
3. **只需要实现 `Interact`**（其余有默认值）。
4. ⚠️ **接口的事件名是 `Can Interact`（带空格），不是 `CanInteract`。**

> 💡 **接口用「BlueprintNativeEvent」的好处**：C++ 有默认实现，蓝图可以选择性地覆盖。
> ⚠️ **陷阱**：`BlueprintNativeEvent` 的 C++ 实现必须叫 `函数名_Implementation`，否则链接错误。

## 6. 机关基类 `ALY_MechanicBase`

```cpp
// LY_MechanicBase.h
#pragma once
#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "Core/LY_Types.h"
#include "Mechanics/LY_Interactable.h"
#include "LY_MechanicBase.generated.h"

DECLARE_DYNAMIC_MULTICAST_DELEGATE_TwoParams(
    FLY_OnMechanicStateChanged, ALY_MechanicBase*, Mechanic, ELY_MechanicState, NewState);

/**
 * 所有机关的公共父类。
 * 只负责：状态 + 事件。不含任何美术资源。
 */
UCLASS(Abstract, Blueprintable)
class LIUYUN_API ALY_MechanicBase : public AActor, public ILY_Interactable
{
    GENERATED_BODY()

public:
    ALY_MechanicBase();

    // ---- 状态 ----
    UFUNCTION(BlueprintPure, Category = "LY|Mechanic")
    ELY_MechanicState GetMechanicState() const { return MechanicState; }

    /** 设置状态，合法则广播事件。蓝图子类不要重写这个。 */
    UFUNCTION(BlueprintCallable, Category = "LY|Mechanic")
    void SetMechanicState(ELY_MechanicState NewState);

    /** 便捷方法 */
    UFUNCTION(BlueprintCallable, Category = "LY|Mechanic")
    void SetActive();

    // ---- 事件（蓝图里 Bind Event 就能收到）----
    UPROPERTY(BlueprintAssignable, Category = "LY|Mechanic")
    FLY_OnMechanicStateChanged OnMechanicStateChanged;

    /** 表现层钩子：蓝图实现。C++ 不写任何美术代码。 */
    UFUNCTION(BlueprintImplementableEvent, Category = "LY|Mechanic")
    void OnStateChangedVisuals(ELY_MechanicState NewState);

    // ---- 交互 ----
    virtual bool CanInteract_Implementation(AActor* Interactor) const override;
    virtual void Interact_Implementation(AActor* Interactor) override;
    virtual FText GetInteractPrompt_Implementation(AActor* Interactor) const override;

protected:
    virtual void BeginPlay() override;

    /** 初始状态，可在关卡/蓝图实例里改 */
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "LY|Mechanic")
    ELY_MechanicState InitialState = ELY_MechanicState::Available;

    /** 是否只能激活一次 */
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "LY|Mechanic")
    bool bOneShot = true;

    /** 交互提示文字 */
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "LY|Mechanic")
    FText InteractPrompt = NSLOCTEXT("LY", "DefaultMechanicPrompt", "按 E 交互");

    UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "LY|Mechanic")
    ELY_MechanicState MechanicState = ELY_MechanicState::Dormant;
};
```

### 6.1 实现要点

```cpp
// LY_MechanicBase.cpp
#include "Mechanics/LY_MechanicBase.h"

ALY_MechanicBase::ALY_MechanicBase()
{
    PrimaryActorTick.bCanEverTick = false;   // ★ 机关默认不需要 Tick
    bReplicates = false;
}

void ALY_MechanicBase::BeginPlay()
{
    Super::BeginPlay();
    SetMechanicState(InitialState);
}

void ALY_MechanicBase::SetMechanicState(ELY_MechanicState NewState)
{
    if (MechanicState == NewState) return;

    // 一次性机关：Completed 之后不能再变
    if (bOneShot && MechanicState == ELY_MechanicState::Completed) return;

    MechanicState = NewState;

    // ★ 先广播（逻辑层监听），再调表现（美术层）
    OnMechanicStateChanged.Broadcast(this, NewState);
    OnStateChangedVisuals(NewState);
}

bool ALY_MechanicBase::CanInteract_Implementation(AActor* Interactor) const
{
    return MechanicState == ELY_MechanicState::Available;
}

void ALY_MechanicBase::Interact_Implementation(AActor* Interactor)
{
    SetActive();   // 子类通常重写
}

FText ALY_MechanicBase::GetInteractPrompt_Implementation(AActor* Interactor) const
{
    return InteractPrompt;
}
```

**三条纪律**：
1. **`bCanEverTick = false`**：机关不需要每帧更新，需要定时用 Timer。
2. **先 `Broadcast` 再 `OnStateChangedVisuals`**：保证逻辑先于表现。
3. **表现层永远不决定状态**：`OnStateChangedVisuals` 只读状态，不改状态。

```cpp
// LY_FirePillar.cpp
#include "Mechanics/LY_FirePillar.h"

ALY_FirePillar::ALY_FirePillar()
{
    InteractPrompt = NSLOCTEXT("LY", "LightPillarPrompt", "按 E 点燃");
}

void ALY_FirePillar::BeginPlay()
{
    Super::BeginPlay();
    bIsLit = bStartLit;
    OnLitVisuals(bIsLit);
}

void ALY_FirePillar::SetLit(bool bNewLit)
{
    if (bIsLit == bNewLit) return;
    bIsLit = bNewLit;

    // 同步机关基类的状态
    SetMechanicState(bIsLit ? ELY_MechanicState::Active : ELY_MechanicState::Available);

    OnPillarLitChanged.Broadcast(this);
    OnLitVisuals(bIsLit);
}

void ALY_FirePillar::Interact_Implementation(AActor* Interactor)
{
    // 默认行为：点亮（记忆谜题里的行为）
    // 联动谜题会由 Manager 覆盖这个行为
    SetLit(true);
}
```

**蓝图 `BP_LY_FirePillar` 要做的事：**

| 蓝图里做什么 | 具体 |
| --- | --- |
| 加网格 | Static Mesh → 方碑/火柱模型 |
| 加碰撞 | 用于射线检测（Visibility 通道） |
| 实现 `OnLitVisuals` | `Branch(bNewLit)` → 换材质实例 / 开粒子 / 播音效 / 开关点光 |
| 加粒子组件 | Niagara `NS_LY_FirePillar`，默认关闭 |
| 加点光源 | 默认亮度 0，点亮时插值到目标值 |
| 加音效 | `S_LY_FireIgnite` |

> ⚠️ **蓝图里绝对不要再写「点燃」的逻辑**。蓝图只响应 `OnLitVisuals`。**逻辑在 C++，表现才在蓝图。** 这是第 8 章「三条铁律」的第一条。

## 8. 旋转光桥 `ALY_RotatingBridge`（含角度对齐）

```cpp
// LY_RotatingBridge.h
#pragma once
#include "CoreMinimal.h"
#include "Mechanics/LY_MechanicBase.h"
#include "LY_RotatingBridge.generated.h"

DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FLY_OnRotationFinished, int32, StepIndex);

UCLASS(Blueprintable)
class LIUYUN_API ALY_RotatingBridge : public ALY_MechanicBase
{
    GENERATED_BODY()

public:
    ALY_RotatingBridge();

    /** 每次旋转的步进角度（默认 90） */
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "LY|RotatingBridge")
    float StepAngle = 90.f;

    /** 需要转到第几步才算对齐（0 = 初始，1 = 转一次） */
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "LY|RotatingBridge")
    int32 TargetStep = 1;

    /** 旋转动画时长 */
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "LY|RotatingBridge")
    float RotateDuration = 1.0f;

    UFUNCTION(BlueprintPure, Category = "LY|RotatingBridge")
    int32 GetStepIndex() const { return StepIndex; }

    UFUNCTION(BlueprintPure, Category = "LY|RotatingBridge")
    bool IsAligned() const { return StepIndex == (((TargetStep % 4) + 4) % 4); }

    UPROPERTY(BlueprintAssignable, Category = "LY|RotatingBridge")
    FLY_OnRotationFinished OnRotationFinished;

    /** 蓝图实现旋转的表现（推荐：Timeline 或 SetRelativeRotation）*/
    UFUNCTION(BlueprintImplementableEvent, Category = "LY|RotatingBridge")
    void OnRotateVisuals(float FromAngle, float ToAngle, float Duration);

    /** 对齐状态变化的表现（光路亮/暗、音效） */
    UFUNCTION(BlueprintImplementableEvent, Category = "LY|RotatingBridge")
    void OnAlignedChanged(bool bAligned);

    virtual void Interact_Implementation(AActor* Interactor) override;
    virtual bool CanInteract_Implementation(AActor* Interactor) const override;

protected:
    UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "LY|RotatingBridge")
    int32 StepIndex = 0;

    UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "LY|RotatingBridge")
    bool bIsRotating = false;

    void FinishRotation();
    FTimerHandle RotateTimer;
};
```

```cpp
// LY_RotatingBridge.cpp
#include "Mechanics/LY_RotatingBridge.h"
#include "TimerManager.h"

ALY_RotatingBridge::ALY_RotatingBridge()
{
    InteractPrompt = NSLOCTEXT("LY", "RotatePrompt", "按 E 旋转");
}

bool ALY_RotatingBridge::CanInteract_Implementation(AActor* Interactor) const
{
    // ★ 旋转中不能交互（防止角度错乱）
    return Super::CanInteract_Implementation(Interactor) && !bIsRotating;
}

void ALY_RotatingBridge::Interact_Implementation(AActor* Interactor)
{
    if (bIsRotating) return;

    bIsRotating = true;

    const float FromAngle = StepIndex * StepAngle;
    StepIndex = (StepIndex + 1) % 4;                 // ★ 取模，0-1-2-3 循环
    const float ToAngle = StepIndex * StepAngle;

    OnRotateVisuals(FromAngle, ToAngle, RotateDuration);

    GetWorldTimerManager().SetTimer(
        RotateTimer, this, &ALY_RotatingBridge::FinishRotation,
        RotateDuration, false);
}

void ALY_RotatingBridge::FinishRotation()
{
    bIsRotating = false;

    const bool bAlignedNow = IsAligned();
    OnAlignedChanged(bAlignedNow);

    if (bAlignedNow)
    {
        SetMechanicState(ELY_MechanicState::Completed);
    }

    OnRotationFinished.Broadcast(StepIndex);
}
```

> 💡 **注意：这里用「步进计数」而不是「浮点角度比较」，这是最稳的做法。**
> 因为每次旋转都是固定 90°，把「转了几次」记为整数，判定永远是 `StepIndex == TargetStep`，**完全避开了浮点误差**。
> **主企划案第 17 章坑 31 给的 `FindDeltaAngleDegrees` 方案，适用于「玩家能自由旋转任意角度」的情况。本项目因为是固定 90° 步进，用整数计数更简单、更可靠。**

**如果一定要用角度比较（自由旋转场景）：**
```cpp
const float Delta = FMath::Abs(FMath::FindDeltaAngleDegrees(CurrentAngle, TargetAngle));
if (Delta < 5.0f) { /* 对齐 */ }
```

**蓝图 `BP_LY_RotatingBridge` 实现 `OnRotateVisuals`：**
1. 用 **Timeline**（0→1，时长 = Duration）驱动 `SetRelativeRotation`。
2. `Lerp` 的起始值是 `FromAngle`，终点是 `ToAngle`。
3. ⚠️ **旋转的是「石柱」组件，不是整个 Actor**（除非你只想转整个物体）。

## 9. 记忆顺序谜题 `ALY_SequencePuzzleManager`

```cpp
// LY_SequencePuzzleManager.h
#pragma once
#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "Core/LY_Types.h"
#include "LY_SequencePuzzleManager.generated.h"

class ALY_FirePillar;

/** 一轮谜题 */
USTRUCT(BlueprintType)
struct FLY_PuzzleRound
{
    GENERATED_BODY()

    /** 正确顺序（MechIndex 列表） */
    UPROPERTY(EditAnywhere, BlueprintReadWrite) TArray<int32> Sequence;

    /** 展示序列时每个方碑的间隔 */
    UPROPERTY(EditAnywhere, BlueprintReadWrite) float ShowInterval = 0.6f;

    /** 关联的宝箱（可选） */
    UPROPERTY(EditAnywhere, BlueprintReadWrite) AActor* RewardChest = nullptr;
};

UCLASS(Blueprintable)
class LIUYUN_API ALY_SequencePuzzleManager : public AActor
{
    GENERATED_BODY()

public:
    ALY_SequencePuzzleManager();

    /** 所有参与谜题的方碑（关卡里拖进来） */
    UPROPERTY(EditInstanceOnly, BlueprintReadOnly, Category = "LY|Puzzle")
    TArray<ALY_FirePillar*> Pillars;

    /** 三轮递增谜题 */
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "LY|Puzzle")
    TArray<FLY_PuzzleRound> Rounds;

    /** 整个谜题完成后开启的东西（风场） */
    UPROPERTY(EditInstanceOnly, BlueprintReadOnly, Category = "LY|Puzzle")
    AActor* CompletionTarget = nullptr;

    UFUNCTION(BlueprintCallable, Category = "LY|Puzzle")
    void StartPuzzle();

    UFUNCTION(BlueprintCallable, Category = "LY|Puzzle")
    void ResetPuzzle();

    UPROPERTY(BlueprintAssignable, Category = "LY|Puzzle")
    FLY_OnMechanicStateChanged OnPuzzleStateChanged;

    /** 表现：点亮某个方碑（蓝图里延时播放） */
    UFUNCTION(BlueprintImplementableEvent, Category = "LY|Puzzle")
    void OnShowSequenceStep(int32 MechIndex, float Interval);

    /** 表现：回合完成/失败反馈 */
    UFUNCTION(BlueprintImplementableEvent, Category = "LY|Puzzle")
    void OnRoundFeedback(bool bSuccess);

    /** 被方碑回调（方碑点亮时把自己的 MechIndex 上报） */
    UFUNCTION()
    void HandlePillarLit(ALY_FirePillar* Pillar);

protected:
    virtual void BeginPlay() override;

    int32 CurrentRound = 0;
    int32 InputIndex = 0;
    bool bShowingSequence = false;

    void ShowCurrentRound();
    void CompleteRound();
    void FailRound();
};
```

**实现要点（伪代码）：**
```
StartPuzzle():
    订阅所有 Pillars 的 OnPillarLitChanged 事件
    CurrentRound = 0
    ShowCurrentRound()

ShowCurrentRound():
    bShowingSequence = true
    熄灭所有方碑
    对第 CurrentRound 轮的 Sequence 里每个 MechIndex：
        OnShowSequenceStep(MechIndex, Interval)   // 蓝图延时点亮
        等待 Interval
    bShowingSequence = false
    InputIndex = 0
    允许玩家输入

HandlePillarLit(Pillar):
    if bShowingSequence: return          // 展示时忽略输入
    Expected = Rounds[CurrentRound].Sequence[InputIndex]
    if Pillar->MechIndex == Expected:
        InputIndex++
        if InputIndex == Sequence.Num(): CompleteRound()
    else:
        FailRound()

CompleteRound():
    OnRoundFeedback(true)
    CurrentRound++
    if CurrentRound >= Rounds.Num():
        OnPuzzleStateChanged.Broadcast(this, Completed)
        触发 CompletionTarget（开启风场）
    else:
        延时 1 秒后 ShowCurrentRound()

FailRound():
    OnRoundFeedback(false)
    延时 0.8 秒后 ShowCurrentRound()      // 重新展示本轮
```

> ⚠️ **核心难点：时序**。展示序列时玩家输入必须被忽略（`bShowingSequence`）。**先让「播放」跑通，再加「校验」。**
> ⚠️ **不要用 Tick 做延时**，用 `FTimerHandle` 或蓝图的 Delay 节点。
> 💡 **为什么把「展示」放到蓝图（`OnShowSequenceStep`）**：因为点亮表现的节奏、音效、粒子是美术向的，放在蓝图里可以随时调。

## 10. 联动翻转谜题 `ULY_ToggleRingPuzzleComponent`

这是**纯逻辑算法**，非常适合放 C++。

```cpp
// LY_ToggleRingPuzzleComponent.h
#pragma once
#include "CoreMinimal.h"
#include "Components/ActorComponent.h"
#include "LY_ToggleRingPuzzleComponent.generated.h"

class ALY_FirePillar;

DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FLY_OnRingSolved, bool, bSolved);

/**
 * 环形联动翻转谜题：
 * 点击第 i 个柱子 → 翻转 i-1、i、i+1（环形）。
 * 全部点亮 = 解开。
 */
UCLASS(ClassGroup=(LY), meta=(BlueprintSpawnableComponent))
class LIUYUN_API ULY_ToggleRingPuzzleComponent : public UActorComponent
{
    GENERATED_BODY()

public:
    ULY_ToggleRingPuzzleComponent();

    /** 环上的柱子，顺序 = 环的顺序（关卡里按顺时针拖入） */
    UPROPERTY(EditInstanceOnly, BlueprintReadOnly, Category = "LY|Puzzle")
    TArray<ALY_FirePillar*> RingPillars;

    UPROPERTY(BlueprintAssignable, Category = "LY|Puzzle")
    FLY_OnRingSolved OnRingSolved;

    /** 玩家点了第 Index 个柱子 */
    UFUNCTION(BlueprintCallable, Category = "LY|Puzzle")
    void HandlePillarClicked(int32 Index);

    /** 重置到初始状态 */
    UFUNCTION(BlueprintCallable, Category = "LY|Puzzle")
    void ResetRing();

    UFUNCTION(BlueprintPure, Category = "LY|Puzzle")
    bool IsSolved() const;

protected:
    virtual void BeginPlay() override;

    /** 初始点亮状态（空 = 全灭） */
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "LY|Puzzle")
    TArray<bool> InitialStates;

    /** 取模索引：环形安全 */
    int32 WrapIndex(int32 Index) const
    {
        const int32 N = RingPillars.Num();
        if (N <= 0) return 0;
        return ((Index % N) + N) % N;      // ★ 处理负数
    }
};
```

```cpp
// LY_ToggleRingPuzzleComponent.cpp
#include "Puzzles/LY_ToggleRingPuzzleComponent.h"
#include "Mechanics/LY_FirePillar.h"

void ULY_ToggleRingPuzzleComponent::HandlePillarClicked(int32 Index)
{
    const int32 N = RingPillars.Num();
    if (N <= 0 || !RingPillars.IsValidIndex(Index)) return;

    // 翻转自己 + 左右相邻（环形）
    const int32 Left  = WrapIndex(Index - 1);
    const int32 Right = WrapIndex(Index + 1);

    RingPillars[Left ]->SetLit(!RingPillars[Left ]->IsLit());
    RingPillars[Index]->SetLit(!RingPillars[Index]->IsLit());
    RingPillars[Right]->SetLit(!RingPillars[Right]->IsLit());

    OnRingSolved.Broadcast(IsSolved());
}

bool ULY_ToggleRingPuzzleComponent::IsSolved() const
{
    for (const ALY_FirePillar* P : RingPillars)
    {
        if (!P || !P->IsLit()) return false;
    }
    return RingPillars.Num() > 0;
}
```

> ⚠️ **`WrapIndex` 必须处理负数**：`(-1) % 6` 在 C++ 里等于 `-1`，不是 `5`！这是新手必踩的坑。
> ✅ 正确写法：`((Index % N) + N) % N`。
> 💡 **写代码前先在纸上验证谜题有解。** 本项目建议初始状态设为「三灭三亮」或「全灭」这种有明确解法的状态。

## 11. 风场 `ALY_WindField`

```cpp

#pragma once
#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "LY_WindField.generated.h"

class UBoxComponent;

UCLASS(Blueprintable)
class LIUYUN_API ALY_WindField : public AActor

public:
    ALY_WindField();

    /** 上升加速度 */
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "LY|Wind")
    float RiseAcceleration = 2000.f;

    /** 最大上升速度（★ 防止飞出地图） */
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "LY|Wind")
    float MaxRiseSpeed = 1200.f;

    /** 到顶后的水平推力（把玩家推向目标平台） */
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "LY|Wind")
    float TopPushSpeed = 600.f;

    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "LY|Wind")
    bool bEnabled = true;

    UFUNCTION(BlueprintCallable, Category = "LY|Wind")
    void SetWindEnabled(bool bNewEnabled);

protected:
    UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "LY|Wind")
    UBoxComponent* WindVolume;

    virtual void BeginPlay() override;
    virtual void Tick(float DeltaSeconds) override;

    UFUNCTION()
    void OnVolumeBeginOverlap(UPrimitiveComponent* OverlappedComp, AActor* Other,
        UPrimitiveComponent* OtherComp, int32 OtherBodyIndex,
        bool bFromSweep, const FHitResult& SweepResult);

    UFUNCTION()
    void OnVolumeEndOverlap(UPrimitiveComponent* OverlappedComp, AActor* Other,
        UPrimitiveComponent* OtherComp, int32 OtherBodyIndex);

    /** 当前在风场里的角色 */
    UPROPERTY()
    TArray<TWeakObjectPtr<AActor>> ActorsInField;
};
```

**实现要点：**
```cpp
void ALY_WindField::Tick(float DeltaSeconds)
{
    Super::Tick(DeltaSeconds);
    if (!bEnabled) return;

    for (const TWeakObjectPtr<AActor>& Ptr : ActorsInField)
    {
        AActor* A = Ptr.Get();
        if (!A) continue;

        if (UPrimitiveComponent* Prim = Cast<UPrimitiveComponent>(A->GetRootComponent()))
        {
            FVector Vel = Prim->GetPhysicsLinearVelocity();

            // ★ 关键：直接设速度 + 上限，不要 AddForce
            const float NewZ = FMath::Min(Vel.Z + RiseAcceleration * DeltaSeconds, MaxRiseSpeed);
            Vel.Z = NewZ;

            Prim->SetPhysicsLinearVelocity(Vel);
        }
    }
}
```

> ⚠️ **三大坑**：
> 1. **不要用 `AddForce`**：力会累积，玩家越飞越快、飞出地图。
> 2. **必须有 `MaxRiseSpeed` 上限**。
> 3. **用重叠事件维护数组，不要每帧扫全场 Actor**（性能）。
> 💡 **角色必须是模拟物理的**（`CharacterMovement` 默认通过速度驱动，所以直接设速度即可；如果你的角色是 `Character` 用 `LaunchCharacter` 更合适）。

**更简单稳妥的替代方案（推荐给初学者）**：
```
进入风场 → 每帧给角色 AddMovementInput(FVector::UpVector, 1.0)
离开风场 → 停
角色自己的跳跃/重力会处理上限
```
**这个方案更「物理正确」，也不会飞出地图。** 如果速度方案不稳定，换成这个。

```cpp
// LY_LightPath.cpp
#include "Mechanics/LY_LightPath.h"
#include "Components/StaticMeshComponent.h"
#include "Materials/MaterialInstanceDynamic.h"

ALY_LightPath::ALY_LightPath()
{
    PathMesh = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("PathMesh"));
    RootComponent = PathMesh;
    PathMesh->SetCollisionEnabled(ECollisionEnabled::NoCollision);

    if (bPathActive == bActive) return;
    bPathActive = bActive;
```

## 14. C++ ↔ 蓝图 常用桥接速查

| 你想做的事 | 用什么 | 写在 C++ 的哪一侧 |
| --- | --- | --- |
| 蓝图里能调用这个函数 | `UFUNCTION(BlueprintCallable)` | 函数声明上 |
| 蓝图里能读这个变量 | `UPROPERTY(BlueprintReadOnly)` | 变量声明上 |
| 蓝图里能改这个变量 | `UPROPERTY(BlueprintReadWrite)` | 变量声明上 |
| 蓝图里能 Bind 这个事件 | `UPROPERTY(BlueprintAssignable)` + `DECLARE_DYNAMIC_MULTICAST_DELEGATE` | 委托声明 |
| C++ 里调蓝图实现的函数 | `UFUNCTION(BlueprintImplementableEvent)` | 不需要 `.cpp` 实现 |
| C++ 提供默认实现，蓝图可覆盖 | `UFUNCTION(BlueprintNativeEvent)` + `_Implementation` | 需要 `.cpp` 实现 |
| 在编辑器里给数组填关卡对象 | `UPROPERTY(EditInstanceOnly)` | 变量声明上 |
| 在蓝图默认值里改参数 | `UPROPERTY(EditAnywhere)` | 变量声明上 |
| 只读调试显示 | `UPROPERTY(VisibleAnywhere)` | 变量声明上 |

### 14.1 最常用的三个委托宏

```cpp
// 无参数
DECLARE_DYNAMIC_MULTICAST_DELEGATE(FLY_OnSomethingDone);

// 一个参数
DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FLY_OnLitChanged, bool, bLit);

// 两个参数
DECLARE_DYNAMIC_MULTICAST_DELEGATE_TwoParams(FLY_OnStateChanged,
    AActor*, Actor, ELY_MechanicState, NewState);
```

> ⚠️ **`DYNAMIC` 是必须的**：只有 Dynamic 委托才能暴露给蓝图。
> ⚠️ **委托声明必须在 `#include "...generated.h"` 之前**（UHT 规则）。

### 14.2 接口在蓝图里怎么用

| 场景 | 做法 |
| --- | --- |
| 蓝图实现接口 | Class Settings → Interfaces → Add |
| 蓝图调用接口 | 用 `Does Implement Interface` 判断 → `Interact` 消息节点 |
| C++ 判断是否实现接口 | `Actor->Implements<ULY_Interactable>()` |
| C++ 调接口函数 | `ILY_Interactable::Execute_Interact(Actor, Interactor)` |

> ⚠️ **在 C++ 里调接口，必须用 `Execute_函数名`**，不能直接 `Interface->Interact()`。这是新手必踩的坑。

| `LNK2019: unresolved external symbol` | 声明了没实现 / `_Implementation` 拼错 |
| `Unrecognized toolchain` | MSVC 版本不对 |
| `Cannot open include file 'X.generated.h'` | `.generated.h` 的 include 不在最后一行 |
| `UnrealHeaderTool failed` | `GENERATED_BODY()` 缺失/位置错 |
