# 配套文档 03 · 美术资产管线与 AI 建模指南（加长版）

> **本文档是主企划案第 10、11、12 章的加长版**，核心目标只有一个：
> **让你用最少的建模工作、接近 0 的成本，做出一个「风格统一、看得过去」的洞天。**
> **前提约束**（来自你的决策）：档位 B、尽量少做美术、偏原神卡通风、预算主要花在 token 上。

---

## 1. 先建立一个正确的美术心态

### 1.1 你的目标不是「像原神」

原神的场景美术是**上百人的团队 + 多年积累的资产库**。任何人以「像原神」为目标，都会绝望。

**你的真实目标**：
> **一个风格统一、色彩成立、能一眼看出「这是个仙侠洞天」的低精度场景。**

用一张图对比：

| 维度 | 原神 | 你（现实目标） |
| --- | --- | --- |
| 模型精度 | 高模 + 手工雕刻 | **低模 / 中模 + 免费素材** |
| 贴图 | 手绘 + 多层材质 | **纯色 + 简单渐变 + 少量手绘** |
| 光照 | 定制渲染管线 | **UE 默认 + Lumen + 后处理调色** |
| 资产数量 | 上千件 | **20～40 件核心资产** |
| 制作人员 | 上百人 | **1 人 + AI** |
| 你的评价标准 | ❌ 不像原神 | ✅ **风格统一、能玩、色彩对** |

### 1.2 「风格统一」比「单个资产精致」重要 10 倍

新手通病：找了一堆来源不同的免费素材，堆在一起像「素材拼盘」——有的写实、有的卡通、有的低模、有的高模。

**解决方案：用「色板 + 统一材质 + 统一光照」强制统一风格。**
即使每个资产来源不同，只要：
1. 颜色都落在你的色板里；
2. 都用同一套光照（青碧环境光 + 金色发光）；
3. 都是低精度风格；

看起来就会「像一个团队做的」。

### 1.3 「少做美术」的四条实操策略

| 策略 | 做法 | 省下时间 |
| --- | --- | --- |
| **① 大色块优先** | 先做好天空、地板、雾、光路——这四样占画面 80% | 巨大 |
| **② 一材多用** | 一套 Master Material + 参数实例，所有石头共用 | 大 |
| **③ 复用 + 改色** | 同一栋建筑模块，用不同缩放/颜色摆出 20 种组合 | 大 |
| **④ 用光照藏拙** | 暗处不建模，用雾和阴影遮盖；亮处才放精细资产 | 中 |

## 2. 美术方向规范（Art Direction）

### 2.1 一句话基调

> **悬浮在青碧虚空中的仙家遗迹：多座浮空石台，由金色发光的光路连接，火与石构成机关，静谧而庄严。**

### 2.2 色板（照抄，这是统一风格的命根子）

**主色 · 青碧虚空（占画面 50%）**

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 天空顶部 | `#1F6E7A` | 最远的深青 |
| 天空中部 | `#2E8C99` | 主体 |
| 近地平线 | `#3FB8C8` | 亮青，形成发光地平线 |
| 仙气点缀 | `#7FE0EA` | 高亮青，用于粒子/高光 |

**强调色 · 暖金（占画面 25%）**

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 光路主色 | `#FFD98A` | 亮金，发光主体 |
| 光路边缘 | `#F2B33D` | 中金，描边 |
| 机关激活 | `#E8A33D` | 深金，暖光 |

**强调色 · 深红橙（占画面 15%）**

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 火柱/方碑 | `#B2354A` | 深红，火焰基色 |
| 火焰中层 | `#C8455C` | 中红 |
| 火焰亮部 | `#FF5C3A` | 橙红，高光 |

**中性色 · 冷灰绿石材（占画面 10%）**

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 石材暗部 | `#7E948F` | 冷灰绿，阴影面 |
| 石材亮部 | `#A8B6B1` | 冷灰绿，受光面 |
| 石台/建筑 | 用以上两色 + 渐变 | — |

> 🎯 **强制规则**：**场景里不允许出现色板之外的高饱和度颜色。** 所有材质都要用这些颜色。这是「风格统一」最有效的强制手段。

### 2.3 情绪曲线

| 阶段 | 色调倾向 | 光照 |
| --- | --- | --- |
| 入口石厅 | 偏暗，冷青 | 低照度 + 火方碑的红光 |
| 旋转桥 | 青碧 + 金色光路亮起 | 光路成为主光源 |
| 浮空岛 A | 青碧为主，红色火柱点缀 | 环境光 + 火光辉映 |
| 风场上升 | 明亮，青碧高扬 | 高亮气流柱 + 天光 |
| 浮空岛 B | 稍暗，红色火柱密集 | 多点红光 |
| 终点庭院 | 最亮，金色最盛 | 金色光柱 + 天光 |

### 2.4 材质关键词

- **石材**：打磨过的青灰石、带仙纹的碑面、苔痕点缀
- **金属**：青铜色机关纹样、氧化感、发光符文
- **光**：金色流动的光路、悬浮的光点、青碧雾气
- **火**：红橙色的仙火、稳定的柱状火焰（不是写实火焰）

### 2.5 声音关键词（音频方向）

- 环境音：高空风声、青碧虚空的「空灵回响」、偶尔的钟鸣
- 机关音：石头旋转的沉闷摩擦、火焰点燃的「轰」、光路接通的清脆「叮」
- BGM：中国风、空灵女声/笛/萧、缓慢的弦乐

## 3. 渲染与光照方案（UE 5.5）

### 3.1 总体方案：Lumen + 后处理调色

| 项目 | 设置 | 理由 |
| --- | --- | --- |
| 全局光照 | **Lumen** | 动态、适合机关发光、免烘焙 |
| 反射 | **Lumen** | 青碧环境反射 |
| 抗锯齿 | **TSR** | 效率高、画面好 |
| 阴影 | **Virtual Shadow Maps** | UE5 默认，质量好 |
| 曝光 | **手动锁定（Manual）** | ★ 最重要的设置 |
| 后期 | **Post Process Volume** | Bloom、色彩、暗角 |

> ⚠️ **4060 Laptop（8GB 显存）跑 Lumen 有压力**。第 9 章会给性能预算。如果掉帧，第一招是把 Lumen 的 `Final Gather Quality` 和 `Reflection Quality` 降到 0.5。

### 3.2 光照组成（三层）

**第一层：环境光（决定氛围）**
- `Sky Light`：颜色染青，Intensity 0.5～1.5
- `Directional Light`：Intensity 2～5 lux，角度斜上方
- `Sky Atmosphere`（可选）：不那么需要，因为我们用自定义天空球

**第二层：机关光（决定视觉焦点）**
- 光路的 Emissive 材质（不需要实际光源，Lumen 会拾取）
- 每个火柱/方碑一个点光源，**只在激活时开**
- 光路接通时，可以在关键位置加一两个点光源增强

**第三层：后期（决定风格）**
- Bloom：Intensity 0.5～1.0（让金色光路发光）
- 色彩分级：Saturation 1.05～1.15，冷色调
- 暗角：轻微

### 3.3 关键设置实操：锁定曝光

1. 拖一个 **Post Process Volume** 进场景，勾 **Infinite Extent (Unbound)**。
2. `Exposure → Metering Mode` 改成 **Manual**。
3. `Exposure → Exposure Compensation` 从 -1 开始调，看画面。
4. （可选）`Min EV100` / `Max EV100` 设为相同值，彻底锁死。

> ⚠️ **Auto Exposure 是「新手画面忽明忽暗」的元凶。** 尤其在洞天这种明暗对比大的场景，玩家转身时画面会突然变亮/变暗，非常廉价。**必锁。**

### 3.4 卡通渲染（Toon Shading）方案

原神用的是定制化的卡通渲染（NPR）。在 UE5 里实现有四种方案，按成本排序：

| 方案 | 成本 | 效果 | 推荐度 |
| --- | --- | --- | --- |
| **A. 后处理描边（Outline）** | 低 | 加一圈黑边，立刻有卡通感 | ⭐⭐⭐⭐⭐ **推荐** |
| **B. 卡通材质（Post Process 强制分级）** | 中 | 明暗分界变硬 | ⭐⭐⭐⭐ 推荐 |
| **C. 完整 NPR 材质（Custom Node）** | 高 | 接近原神 | ⭐⭐ 太难 |
| **D. 用现成插件** | 中 | 效果不错 | ⭐⭐⭐ 可选 |

**推荐组合：A + B**

#### 方案 A：后处理描边（最快见效）

1. 新建一个 Post Process Material（`M_LY_Outline`）。
2. 用 `SceneTexture: Depth` 做边缘检测（Sobel 或简单邻近采样）。
3. 边缘处输出黑色（或深色）。
4. 加到 Post Process Volume 的 `Post Process Materials` 数组里。

> 💡 **这一步能立刻让画面「变成卡通」，强烈建议做。** 网上有大量「UE5 outline post process」教程，跟着做一个小时就能搞定。

#### 方案 B：卡通光照分级

1. 做一个 Master Material，用 `Lighting` 节点拿光照，然后用 `Floor` / `Step` 把光照分成 2～3 级。
2. 明暗交界变硬，就是卡通感。
3. ⚠️ 这个方案需要一些材质知识，如果做不出来，**只用方案 A 也够了**。

> ⚠️ **不要追求「完整 NPR」**。你的目标是「看起来像卡通」，不是「复刻原神渲染管线」。**后处理描边 + 统一色板，已经能达到 80% 的观感。**

## 4. 少做美术的四个「偷懒」技巧

### 4.1 用「大色块 + 雾」代替细节

远处的浮空平台不需要建模细节。做法：
- 放一个很简单的几何体（Cube/Cylinder）
- 用接近天空色的材质
- 加大量的雾
- 玩家根本看不清细节，只会觉得「远处有东西」

> 💡 **雾是最好的「省美术」工具。** 它把远处的东西糊掉，你的低模就藏起来了。

### 4.2 用「发光」吸引注意力，掩盖低精度

金色光路是发光的，玩家的注意力会被高光吸引，忽略周围石材的粗糙。
**把最精细的资产放在光路附近，其他地方可以很简。**

### 4.3 用「重复 + 变化」代替「设计很多资产」

| 需要 | 做法 |
| --- | --- |
| 10 种不同的柱子 | 1 种柱子 × 不同高度/颜色/旋转/组合 |
| 一片建筑群 | 1 套模块（墙/柱/顶/地）× 自由组合 |
| 一片石头 | 1 个石头 × 随机缩放/旋转（ISM） |

> 💡 **可以埋一两个「残缺的柱子」**（倾斜、断裂）来制造「古迹感」，成本几乎为 0。

### 4.4 用「光照对比」引导视线

把不该看的藏在暗处，该看的用光照亮。**人眼只会看亮的地方。**

### 5.3 ⚠️ 关于「原神官方模型」

你提到想用「旅行者」的模型。**明确建议：不要用。**

原因：
1. **版权**：从游戏里提取的模型是米哈游的资产，未经授权使用属于侵权。
2. **你投的是米哈游**：在面试材料里放侵权资产，是**最糟糕的负面信号**。
3. **技术上也麻烦**：提取的模型往往缺骨骼、材质错乱、需要大量修复。

**替代方案（见第 6 节）**：用 VRoid Studio 生成一个**原创的、风格接近的**角色。

## 6. 角色方案（回答你「用旅行者建模」的问题）

### 6.1 结论

> **不要用官方旅行者模型。用 VRoid Studio 生成一个原创卡通角色，风格接近即可。**

### 6.2 为什么推荐 VRoid Studio

| 优势 | 说明 |
| --- | --- |
| **免费** | 完全免费 |
| **卡通风格** | 日系动漫风格，接近原神气质 |
| **可捏脸/换装** | 不需要建模，像玩游戏一样调整 |
| **导出 VRM** | 标准格式，有 UE 插件 |
| **原创** | 完全属于你，无版权风险 |
| **快** | 2～3 小时能做出一个能看的角色 |

### 6.3 角色方案对比

| 方案 | 成本 | 风格接近度 | 版权 | 技术难度 | 推荐 |
| --- | --- | --- | --- | --- | --- |
| 官方旅行者模型 | 0 | 100% | ❌ 侵权 | 中 | ❌ **不要** |
| **VRoid 原创角色** | 0 | 70% | ✅ 原创 | 低 | ⭐⭐⭐⭐⭐ **推荐** |
| Mixamo 预设角色 | 0 | 30% | ✅ 可用 | 低 | ⭐⭐⭐ 备选 |
| UE 商城卡通角色 | 0～$ | 60% | ✅ 可用 | 低 | ⭐⭐⭐⭐ 可用 |
| AI 生成角色（Meshy 等） | 有限免费 | 50% | ⚠️ 模糊 | 中 | ⭐⭐ 备选 |
| 自己建模 | 时间 | 看水平 | ✅ | 高 | ❌ 不划算 |

### 6.4 VRoid → UE5 完整流程

**第 1 步：安装 VRoid Studio**
- 官网下载（免费），Windows 版。
- 安装后，选一个基础模型开始。

**第 2 步：捏角色（2～3 小时）**
- 调整脸型、发型、肤色、眼睛。
- **服装**：VRoid 自带一些服装，也可以导入别人做的（注意授权）。
- **配色**：让角色色板和场景协调（青碧 + 金 + 白）。
- 目标：**一个「仙侠风、长发、浅色衣服」的角色**即可，不需要像旅行者。

**第 3 步：导出 VRM**
- `File → Export → VRM`，保存为 `.vrm`。
- ⚠️ 注意导出时的**材质/贴图选项**，选「导出贴图」。

**第 4 步：导入 UE5**
两种方式：
- **方式 A（推荐）**：用 **VRM4U** 插件（免费，GitHub 上搜 `VRM4U`）。
  1. 下载插件，放到项目的 `Plugins/` 目录。
  2. 重新生成项目文件、编译。
  3. 直接把 `.vrm` 拖进 Content Browser。
- **方式 B**：用 Blender 中转（VRM → FBX → UE）。
  1. Blender 装 VRM 导入插件。
  2. 导入 VRM，导出 FBX（勾 `Apply Transform`，缩放注意）。
  3. 导入 UE。

**第 5 步：接动画**
- **Mixamo**：上传角色或直接用 Mixamo 预设角色，下载动画（Walking、Idle、Jumping 等）。
- ⚠️ Mixamo 的骨架和 VRM 骨架可能不匹配，需要**重定向（Retargeting）**。
- UE5 有 **IK Retargeter**，可以把 Mixamo 动画重定向到你的角色。

> ⚠️ **常见坑：缩放不对**。VRM 的单位是米，UE 是厘米。导入后角色可能是「巨人」或「蚂蚁」。
> **解决**：导入时检查 Scale（通常需要 ×100），或导入后在角色的 Skeletal Mesh 上调整。

### 6.5 动画方案（最低成本）

| 需要 | 来源 | 说明 |
| --- | --- | --- |
| Idle | Mixamo | 待机动画 |
| Walk / Run | Mixamo | 走路/跑 |
| Jump | Mixamo | 跳跃 |
| Interact | Mixamo | 拾取/推（复用） |
| 对话 | Mixamo | 站立说话（可用 Idle 代替） |

> 💡 **不需要自定义动画。** 用 Mixamo 的免费动画 + 重定向，足够这个 Demo。**动画不是你的重点。**

## 7. AI 建模工具与工作流

### 7.1 结论先行（三条）

1. **没有任何工具能「一键生成整个洞天」**。别抱幻想。
2. **AI 最适合生成「装饰性道具」**：石头、灯、雕像、宝箱。**不适合核心机关**（机关要精确尺寸）。
3. **最可靠的 AI 辅助链路**：AI 生成贴图 + AI 生成装饰道具 + 你（或用 AI 写的脚本）做核心几何。

### 7.2 AI 3D 生成工具（文本/图片 → 3D）

| 工具 | 类型 | 免费额度 | 质量 | 适合 |
| --- | --- | --- | --- | --- |
| **Meshy** | 文/图生 3D | 有（有限） | 中 | 装饰道具 |
| **Tripo AI** | 文/图生 3D | 有（有限） | 中上 | 装饰道具 |
| **Rodin** | 图生 3D | 有 | 中上 | 道具、雕像 |
| **Luma Genie** | 文生 3D | 有 | 中 | 快速原型 |
| **Sloyd** | 参数化 3D | 有 | 中 | 建筑模块 |
| **Adobe Substance 3D** | 材质 | 订阅 | 高 | 材质生成 |

> ⚠️ **AI 生成的模型通常**：面数高、拓扑乱、UV 差、不能直接用于动画。**适合做静态装饰物**，导入 UE 后要处理碰撞、面数、材质。

### 7.3 Blender AI 插件

| 插件 | 作用 |
| --- | --- |
| **Dream Textures** | 用 AI 生成贴图（免费） |
| **AI Render** | 用 Stable Diffusion 风格化渲染 |
| **BlenderGPT** | 用自然语言控制 Blender |
| **Rodin / Meshy 插件** | 直接在 Blender 里生成 3D |

### 7.4 Codex 能帮你做什么（重要）

**诚实回答：Codex 不能直接生成 3D 模型。** 但它能做这些：

| 你能让 Codex 做的事 | 说明 |
| --- | --- |
| **写 Blender Python 脚本** | 程序化生成中式石柱、栏杆、台阶等规则几何 |
| **写 UE Python 脚本** | 批量导入 FBX、批量设置缩放/碰撞/材质 |
| **写 UE C++ 工具类** | 在编辑器里程序化摆放物体 |
| **生成材质节点逻辑** | 描述清楚需求，Codex 给你 HLSL 或节点图说明 |
| **写资产整理脚本** | 批量重命名、批量移动资产 |
| **查资料、做技术选型** | 「这个效果怎么做」的最佳实践 |

**示例：让 Codex 生成一个中式石柱（Blender Python）**
```python
# 伪代码示例——实际使用时让 Codex 补全
import bpy

# 1. 创建立方体底座
# 2. 创建圆柱柱身
# 3. 加倒角修改器
# 4. 加雕花（用阵列 + 简易几何）
# 5. 导出 FBX
```

> 💡 **这是最实际的「AI 建模」路径**：**你描述需求 → Codex 写脚本 → Blender 执行 → 导出 FBX → 导入 UE。**
> 对于**规则几何**（柱子、台阶、栏杆、平台、方碑），这条链路非常高效。

### 7.5 关于「AI 建模 skill / Codex 插件」

你问能不能找到「AI 建模 skill 或 Codex 插件」。**诚实回答：**

| 你想要的 | 是否存在 | 说明 |
| --- | --- | --- |
| Codex 插件能直接生成 3D 模型 | ❌ 没有 | Codex 是代码/文本环境，没有 3D 生成能力 |
| Codex 能写 Blender 脚本驱动建模 | ✅ **能** | 见 7.4，**这是最实际的路径** |
| Blender 的 AI 插件 | ✅ 有 | Dream Textures、AI Render、Rodin、BlenderGPT |
| UE 的 AI 插件 | 🟡 少 | 主要是 AI 助手类（解释代码、生成蓝图节点），**不建议在项目里依赖** |
| AI 云平台（Meshy/Tripo） | ✅ 有 | 文/图生 3D，见 7.2 |

> **一句话总结**：**不要指望「一键生成整个洞天」。** 真实可用的 AI 链路是：
> **AI 生成贴图（Dream Textures）+ AI 生成装饰道具（Meshy/Tripo）+ 你（或 Codex 写的脚本）做核心机关几何 + VRoid 做角色。**

### 7.6 AI 生成资产的「风格统一」问题

AI 生成的最大问题是**每次生成的风格都不一样**。解决：
1. **用同一个 prompt 模板**，只改主体描述（如「中式石灯，青灰色石材，卡通低模风格，正面视角，白底」）。
2. **生成后统一处理**：在 UE 里给所有 AI 资产生成**同一套材质**（用你的色板）。
3. **限制使用场景**：AI 资产只放远景/装饰，不放核心机关。

## 8. 材质规范（统一风格的关键）

### 8.1 Master Material 策略

**只做 2～3 个 Master Material，其他全是它的实例。**

| Master Material | 用途 | 参数 |
| --- | --- | --- |
| `M_LY_Stone_Master` | 所有石材 | BaseColor、Roughness、Normal 强度 |
| `M_LY_Metal_Master` | 金属/机关 | BaseColor、Metallic、Emissive 强度 |
| `M_LY_Emissive_Master` | 光路/发光物 | Emissive Color、强度、流动速度 |

**每个实例只改参数**（如 `MI_LY_Stone_Light` / `MI_LY_Stone_Dark`）。

### 8.2 石材材质要点

- BaseColor 用色板里的冷灰绿
- Roughness 0.6～0.8（石头不反光）
- Normal 用简单的纹理（ambientCG 免费下载）
- **加一点「世界坐标衰减」**，让靠近地面的地方更暗（增加真实感）

### 8.3 发光材质要点（光路的核心）

- Emissive Color 用金色 `#FFD98A`
- **Emissive Intensity 要够高**（5～20），让 Bloom 能抓到
- 加**流动效果**：用 Texture Coordinate 的 U 方向 + Time 节点驱动光点移动
- 光路边缘用更亮的颜色描边

## 9. 素材工作流（从下载到进 UE）

### 9.1 标准流程

```
① 确认授权  →  ② 下载  →  ③ 记录 AssetCredits  →  ④ 导入 UE
   →  ⑤ 检查缩放/朝向/碰撞  →  ⑥ 赋材质  →  ⑦ 摆进关卡
```

### 9.2 导入 UE 的注意事项

| 项目 | 注意 |
| --- | --- |
| **缩放** | 检查单位（cm vs m），FBX 导入时看 Scale |
| **朝向** | 不同软件的「前方」不一样，导入后可能要旋转 |
| **碰撞** | 至少加简单碰撞（Box/Convex），否则玩家会穿过去 |
| **面数** | 高模开启 Nanite；低模直接导入 |
| **材质** | 导入的材质要替换成你的 Master Material |
| **LOD** | 远景资产做 LOD，减面 |

### 9.3 `AssetCredits.md` 格式（每个素材一行）

```markdown
| 资产名 | 用途 | 来源 | 作者 | 授权 | 下载日期 | 备注 |
```

## 11. 常见美术坑（本章专属）

| 坑 | 症状 | 解决 |
| --- | --- | --- |
| 素材来源太杂 | 像拼盘 | 用统一色板 + Master Material 强制统一 |
| 导入缩放不对 | 资产过大/过小 | 导入时检查单位（cm/m） |
| 导入朝向不对 | 资产躺倒/背对 | 导入后旋转修正 |
| 忘了加碰撞 | 玩家穿模 | 每个资产加简单碰撞 |
| 高模没开 Nanite | 掉帧 | 静态高模开 Nanite |
| 材质不统一 | 有的写实有的卡通 | 全部换成你的 Master Material |
| 光照过暗/过曝 | 看不清/刺眼 | 锁定曝光 + 调 Compensation |
| 自动曝光 | 画面忽明忽暗 | **改 Manual** |
| 光路不发光 | 没有仙侠感 | 提高 Emissive Intensity + Bloom |
| 雾太浓 | 糊住场景 | 降低 Density |
| 用了侵权资产 | 法律风险 | 只用 CC0/CC-BY/授权明确的 |
| AI 资产风格不统一 | 像拼盘 | AI 资产只放远景，统一材质 |
| 忘记记 AssetCredits | 最后无法整理 | 引入时立刻记录 |
