## 一、设计宣言

> **悬浮在青碧虚空中的仙家遗迹：多座浮空石台，由金色发光的光路连接，火与石构成机关，静谧而庄严。**
>
> 玩家不是被敌人阻拦，而是被**空间本身**考问。

这套美术规范服务于一个目标：**用最少的建模工作量，做出「风格统一、一眼能认出是洞天」的画面。**
你主要练 gameplay，所以本规范的所有决策都偏向「**降低美术成本、提高风格一致性**」，而不是「逼近原神画质」。

## 二、全局基调

| 维度 | 设定 |
| --- | --- |
| 场景类型 | 悬浮于青碧虚空的**洞天秘境**，多座浮空石台 |
| 主色调 | 青碧虚空（50%）+ 暖金（25%）+ 深红橙（15%）+ 冷灰绿石材（10%） |
| 光源逻辑 | **天空即主光**；金色光路是第二光源；火柱是局部红光；**没有洞穴暗部** |
| 材质关键词 | 打磨青灰石、碑面仙纹、青铜机关、发光金色光路、红橙仙火、青碧雾气 |
| 声音关键词 | 高空风声、虚空空灵回响、石头阻尼摩擦、火焰点燃、光路接通的清脆「叮」、悠远钟鸣/笛 |
| 情绪曲线 | 静谧起手 → 试探 → 掌握 → 升高（风场）→ 紧张（联动谜题）→ 登顶释然 |

> 🎯 **和旧版最大的区别：整个关卡是「明亮的」，不是「昏暗的」。** 如果你发现自己做的场景一片黑、需要靠点光源照明，那就是走回了旧方向，**立刻停下检查天空光和雾**。

## 五、机关视觉语义（严格遵守，不得例外）

> 原神的机关之所以「一眼就懂」，是因为**同一状态在所有机关上都长得一样**。你的 Demo 也必须这样。

| 状态 | 视觉表现 |
| --- | --- |
| 可交互 · 未激活 | 淡青蓝色呼吸光（`#7FE0EA`），慢速脉动，周期约 2 秒 |
| 已激活 | 稳定金色光（`#FFD98A`），纹样点亮，**不再脉动** |
| 不可用 · 锁定中 | 完全无光，材质发暗发灰（`#7E948F`） |
| 需要玩家前往 | 细光柱 / 粒子流指向目标方向 |
| 谜题完成 · 全亮 | 全场统一金色，可加一次「扩散光波」 |

> ⚠️ **火柱「点亮/熄灭」的红色火焰与「光路接通」的金色是两套语言，不要混用。**
> 火柱 = 红橙（`#B2354A`~`#FF5C3A`）；光路/机关激活 = 暖金（`#FFD98A`~`#E8A33D`）。

## 六、关键道具外观规范

| 道具 | 外观 | 建模成本 |
| --- | --- | --- |
| **火元素方碑 / 火柱** | ⚠️ 依据截帧修正：**不是圆柱，是扁平的矩形「门框/牌坊」造型**——红色发光的外框 + 内部符文 + 顶部悬浮红色水晶/火焰。未激活暗淡，激活时通体红光 + 粒子 | 低（一个 Box 环 + 材质即可） |
| **方形石柱机关** | 深蓝/青色方形石柱，四面方形发光纹样，整体可旋转，顶部有机关核心 | 低 |
| **小石灯** | 青蓝色（青灰）六角/方顶灯罩，内部橙色火光，沿石台边缘等距排列，**是重要的节奏点装饰** | 极低（复制粘贴） |
| **光路 / 光桥** | 金色线条 + 发光地板，连接两座平台。**全关卡最强的视觉引导** | 极低（材质） |
| **地面石台** | 圆形石台，同心圆刻纹 + 同心方框几何纹样（**这是场景里辨识度最高的图案，务必做**） | 低（可复用同一套） |
| **宝箱** | 仙家风格的青铜/木宝箱 | 极低（找免费素材） |
| **终点庭院 / 拱门** | ⚠️ 截帧新增：场景里有**巨大的圆形石拱门**（青灰色，立在平台上，是很好的构图框架与地标）。终点另有石阶、门扉、白鹤、石灯 | 中（拱门可简化成圆环） |

## 七、打光原则

1. **天空即主光。** 先做好天空球 + 指数高度雾，再考虑其他灯。天空对了，画面就对了一半。
2. 优先用**光照对比**引导，而不是 UI 文字：**每个「该去的地方」必须比周围至少亮一档**。
3. 动态光源总数控制在 **8 个以内**，其余用自发光材质 + Lumen 拾取。
4. **关闭或锁定 Auto Exposure。** 明暗对比大的场景里，自动曝光是「画面忽明忽暗」的头号元凶。
5. 金色光路用 **Emissive 材质**，不必每个都配真实光源（Lumen 会拾取）。

## 八、渲染方案速查（UE 5.5）

| 项目 | 设置 |
| --- | --- |
| 全局光照 / 反射 | Lumen |
| 抗锯齿 | TSR |
| 阴影 | Virtual Shadow Maps |
| 曝光 | **Manual（手动锁定）** ★ |
| 后期 | Post Process Volume：Bloom 0.5~1.0 + 轻微暗角 |

**卡通化推荐组合（成本最低见效最快）：**

- **方案 A · 后处理描边**（⭐⭐⭐⭐⭐ 强烈推荐）：Post Process Material 用 SceneTexture:Depth 做边缘检测，边缘输出深色。**一两个小时就能做完，画面立刻「变成卡通」。**
- **方案 B · 卡通光照分级**：Master Material 用 `Floor`/`Step` 把光照分 2~3 级。（可选，做不出来只用 A 也够）

> ⚠️ **不要追求「完整 NPR」。** 你的目标是「看起来像卡通」，不是「复刻原神渲染管线」。
> **后处理描边 + 统一色板，已经能达到 80% 的观感。**

## 九、材质规范（统一风格的关键）

- **唯一的 Master Material 策略**：地板一套、建筑一套、发光体一套，共 **3 套 Master Material**，其余全部用**参数化实例**。
- **不要给每个道具做独立材质。** 新手最常见的浪费就在这里。
- 所有石材材质必须能调两个参数：**暗部色 / 亮部色**，且默认值就是本规范的冷灰绿。
- 自发光材质统一暴露 **发光颜色 + 强度** 两个参数，方便在蓝图上切换激活状态。

## 十、禁止事项（贴在显示器上）

- ❌ 禁止把场景做成**昏暗洞穴**（旧版方向，已作废）。
- ❌ 禁止出现**色板之外的高饱和度颜色**。
- ❌ 禁止单个机关长得和别的机关完全不同（玩家会不知道能不能交互）。
- ❌ 禁止用**纯文字提示**替代视觉引导。
- ❌ 禁止在**灰盒验收通过前**替换美术资产。
- ❌ 禁止给每个道具做独立材质（浪费数天）。
- ❌ 禁止追求写实渲染 / 完整 NPR / 复刻原神画质。
- ❌ 禁止使用任何从《原神》提取的模型、贴图、音乐（侵权，且你投的是米哈游）。
